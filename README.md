Supplementary Table: The ranked epitopes predicted and evaluated in silico for Multi-Epitope Vaccine (MEV) Against Echinococcus granulosus.

Echinococcus Isolates sheet  
All available protein sequences from  Echinococcus species that accessed 28 September 2024.

MHCI Epitopes sheet 
MHCI-Peptide: The shared MHCI-Peptide predicted  by three methods (Consensus, NetMHCpan, and ANN)
MHCI prediction frequency: According to the epitope redundancy in different proteins and for MHC I alleles promiscuity.
Promiscuous Alleles: The variant MHC I alleles that could predict the same epitope.
MHCI allele Count: Number of variant MHC I alleles that could predict the same epitope.
MHCI antigenicity Score: Which provided by VaxiJen v2.0. 
MHCI immunogenicity avrage: For Six MHC I alleles which provided by Class I Immunogenicity tool in IEDB.
CTL epitope score: Which were ranked and normalizated after calculated as (Antigenicity score Immunogenicity score (CD8)+MHCI prediction frequency + MHCI allele Count (Promiscuous)).
Protein ID: That epitope belong to.

MHCII Epitopes sheet 
MHCII-peptide:The shared MHCII-Peptide predicted  by (Consensus3 and NetMHCIIpan) methods.
MHCII prediction frequency: According to the epitope redundancy in different proteins and for MHC II alleles promiscuity
MHCII  Alleles: The  MHC II alleles that could predict the same epitope.
Core_peptide: Which provided by predicted methods.
Core repeat count: The count of repeated core in different predicted epitopes.
Antigenicity score_15AA: Which provided by VaxiJen v2.0. 
Immunogenicity Score: which provided by CD4 T-cell Immunogenicity tool in IEDB.
HTL epitope score:  Which were ranked and normalizated after calculated as (Antigenicity score+ Immunogenicity score (CD4)+MHCII prediction frequency + MHCII core repeat count)
Protein ID: That epitope belong to.

B-Cell protein score sheet
Protein ID: The shared 68 proteins for linear and conformational predicted epitopes.  
N.of B-Cell-Dis-Epitopes(Ellipro): Number of discontinuous epitopes predicted by Ellipro tool.
Discontinous Score(Ellipro): Score of discontinuous epitopes predicted by Ellipro tool
N.of B-Cell-Dis-Epitopes(discotop): Number of discontinuous epitopes predicted by discotop tool.
Discontinuous epitope score: Which were normaliziated after calcuated as (Dis-Epitopes count (ElliPro)+ Dis-Epitopes Score (ElliPro)+ Dis-Epitopes count (DiscoTope))
Count_12aa-bepipred: Number of 12aa continuous epitopes predicted by bepipred tool.
Avg_linear_score_12aa-bepipred: Averge score for 12aa linear epitopes predicted by bepipred tool.
Count_15aa-bepipred: Number of 15aa continuous epitopes predicted by bepipred tool.
Avg_linear_score_15aa-bepipred: Averge score for 15aa linear epitopes predicted by bepipred tool.
Count_16aa-bepipred: Number of 16aa continuous epitopes predicted by bepipred tool.
Avg_linear_score_16aa-bepipred: Averge score for 16aa linear epitopes predicted by bepipred tool.
Total_avg-count aa: Averge of total continuous epitopes number predicted by bepipred tool.
Total_ avg-linear score: Averge score for total linear epitopes predicted by bepipred tool.
Linear epitope score: Which were normaliziated after calcuated as (Average count 12, 15, 16 aa (BepiPred)+ Average linear score 12, 15, 16 aa (BepiPred)).
B-Cell-protien score: Which were calcuated as (Linear epitope score+ Discontinuous epitope score)

LB Epitopes sheet
LB-peptide: The 15aa linear epitopes predicted by bepipred tool.
antigenicity score: Which provided by VaxiJen v2.0. 
Ig Score: Which provided by IgPred tool.
Ig Prediction: Which provided by IgPred tool.
B-Cell-protien score: Which were calcuated as (Linear epitope score+ Discontinuous epitope score).
LB EPITOPE  SCORE: Which were ranked and normalizated after calcuated as (Antigenicity score+ Immunogenicity score (Ig) + B Cell protein score).
Protein ID: That epitope belong to.
